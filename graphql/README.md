# Сервис Graphql

## Основы для работы
Схема приложения изменяется в файле `schema.graphql`

## Валидация схемы
Валидация схемы происходит за счет `Node.js`. Для ее запуска следуйте шагам ниже (требуются установленные [node.js и npm](https://nodejs.org/en/download)):

1. Установите зависимости

```bash
cd ./graphql
npm i
```

2. Запустите валидацию

```bash
npm run validate
```
